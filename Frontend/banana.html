How it works

  • You'll receive five visual puzzles.
  • Find the missing digit between 0 and 9.
  • Each correct answer earns 20 points.
  • The server checks answers and saves your final score.

Powered by the Banana API

Questions are fetched from the University of Bedfordshire Banana API example service. The correct answers remain on the server until you submit a guess.

The external service requires an internet connection and may occasionally be unavailable.
